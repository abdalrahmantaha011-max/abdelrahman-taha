## 🛠 Tech Stack

The project is built using a modern frontend stack for speed and scalability:

* **Framework:** React with Vite (for ultra-fast development and bundling).
* **Language:** TypeScript (to ensure type safety and cleaner code).
* **Styling:** Tailwind CSS (for utility-first, responsive styling).
* **UI Components:** shadcn/ui (reusable components built on top of Radix UI).

## 💻 Local Development

If you'd like to run this project locally, follow these steps:

1.  **Clone the repository:**
    ```sh
    git clone <YOUR_GIT_URL>
    ```

2.  **Install dependencies:**
    ```sh
    npm install
    ```

3.  **Start the development server:**
    ```sh
    npm run dev
    ```
